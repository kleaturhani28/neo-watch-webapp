NASA API configuration

The NASA API key must not be stored in frontend code. Later, the backend will read it from environment variables. 

NASA_API_KEY=your_key
REDIS_URL=redis://...
CACHE_TTL_FEED_SECONDS=21600
CACHE_TTL_DETAIL_SECONDS=86400

The frontend will call only your backend endpoints.
